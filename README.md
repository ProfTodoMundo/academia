# Academia de Analítica Aplicada

Landing page estática para ofrecer sitios web profesionales a académicos, docentes e investigadores.

## Publicación con GitHub Pages

1. Crea un repositorio público en la cuenta `ProfTodoMundo`, por ejemplo `academia-analitica-aplicada`.
2. Sube `index.html` y este archivo `README.md` a la rama `main`.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`; después pulsa **Save**.
6. El sitio quedará disponible en una dirección similar a:
   `https://proftodomundo.github.io/academia-analitica-aplicada/`

## Dominio personalizado

Posteriormente puede configurarse un dominio o subdominio propio desde GitHub Pages y el proveedor DNS.
